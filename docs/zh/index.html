M5Stack Tab5 · Performance Synthesizer

触摸、塑造、演奏。

Tab5 Synth 把振荡器、麦克风采样、外部 I2S 输入、ADSR 包络、四组效果器、逐参数 LFO、预设、XY 触控板和触摸键盘整合为一台最多 7 复音的合成器。

制作第一个声音在单独页面打开模拟器
7 voices最多同时演奏 7 个音符
6 sourcesSINE / SAW / SQUARE / TRIANGLE / MIC / I2S
17 targets每个 AMP 与 FX 参数都有独立 LFO

快速入门

基本流程是：选择目标 → 用底部横向推子调值 → 用键盘或 XY 触控板演奏。

选择音源

先点 SINE 或 SAW。锯齿波明亮、泛音丰富，很适合主音和铺底音色。

设置音量

打开 AMP，选择 VOL，提高横向数值推子。

塑造音符

调节 ATK / DEC / SUS / REL，中央包络图会同步变化。

开始演奏

触摸键盘；在 XY 板上，X 控制音高，Y 提供演奏位置。

三种界面皮肤

操作界面提供三种外观。切换皮肤只改变显示效果，不会改变音色参数、效果器、LFO 设置或当前演奏状态。

RETRO WOOD

Retro Wood

默认皮肤，采用胡桃木、黄铜和暖色琴键，呈现复古乐器风格。

METAL

Metal

使用拉丝金属、银色边框和深色控制面板，接近录音室设备风格。

NEON

Neon

使用青色、品红色、黄绿色发光元素和数字网格的霓虹风格。

点击左上角

点击左上角的 TAB5 / PERFORMANCE SYNTHESIZER 区域，或点击 01 SOURCE 标题区域。

依次切换

每次点击按 WOOD → METAL → NEON → WOOD 的顺序切换。

确认状态

顶部状态栏会显示 WOOD THEME、METAL THEME 或 NEON THEME。

启动皮肤：当前实现每次启动时使用 Retro Wood。皮肤选择不会保存在 M1–M5 中。

01 · 音源

顶部一行决定原始声音。“sing” 通常是对 SINE（正弦波）的误写。除了四种振荡器波形，还可使用麦克风采样和 I2S 数字输入。

SINE

纯净圆润，适合次低音、长笛和柔和主音。

SAW

明亮、泛音丰富，适合弦乐、铜管、贝司和强劲主音。

SQUARE

空心而电子化，适合 8-bit、贝司和簧片类音色。

TRIANGLE

比正弦波多一点泛音，适合钟声和柔和贝司。

MIC

按住时录音，松开时生成采样；不足 1 秒会丢弃，最长 5 秒。

I2S

接收外部数字音频；当前输入采样率为 16 kHz。

MIC 操作：按住 MIC 至少 1 秒并输入声音，然后松开。显示 MIC READY / SAMPLED / READY 后即可演奏。网页模拟器用于体验界面；实际录音和发声需要 Tab5 硬件。

AMP · 音量与包络

AMP 决定整体音量，以及从按键到松键期间音量如何变化。先选择旋钮，再用编辑器底部共用的 0–100 推子修改。

音量

VOL
最终输出音量。失真或多音演奏使电平叠加时可适当降低。

ADSR

ATK
Attack：按键后到达峰值的时间。小值更锐利，大值缓慢淡入。
DEC
Decay：从峰值下降到保持电平的时间。
SUS
Sustain：按住键时维持的电平。它是音量，不是时间。
REL
Release：松键后到完全静音的时间。
A按下 → 峰值D峰值 → 保持S按住期间R松开 → 静音

示例：打击感 PLK 可用快速 ATK、短 DEC、低 SUS；PAD 则提高 ATK 与 REL，得到缓慢出现和长尾音。

FX · 效果器

效果器名称按钮同时用于选择和开关。即使旁路，参数仍可编辑；中间三个旋钮始终属于当前选中的效果器。

DRY SOURCE›DELAY›CHORUS›DRIVE›CRUSH›OUTPUT

DELAY · 回声

TIME
原声与回声之间的间隔。
FBK
反馈量；越高，重复次数越多。
MIX
延迟声与原声的混合比例。

CHORUS · 宽度

RATE
合唱摆动速度。
DEP
音高/时间调制深度。
MIX
合唱声混合量。

DRIVE · 失真

DRV
失真强度和增益。
TON
失真后的明暗平衡。
MIX
失真声混合量；较低时保留更多原声起音。

CRUSH · Lo-fi

BITS
量化粗糙度；提高后位深破碎感更强。
RATE
降低采样更新率，产生数字混叠和高频破碎。
MIX
破碎处理声混合量。

LFO · 自动调制

LFO 用低频波形自动移动所选参数。17 个 AMP 与 FX 目标分别保存自己的 Rate、Depth、Wave 和开关状态。

选择目标

先在 AMP 或 FX 中选择要调制的参数，例如 VOL 或 DELAY TIME。

打开 LFO

切到 LFO，确认顶部 TARGET 是所需参数。

设置运动

RAT 是速度，DEP 是幅度；选择 SINE、TRIANGLE、SQUARE 或 RND。

启用

点击 LFO ON。切换目标时会调用该目标自己的设置。

波形运动常见用途
SINE圆滑循环颤音、柔和音量变化
TRIANGLE匀速上升下降平稳机械扫描
SQUARE在两个值间瞬时切换震音、节奏门限感
RND随机变化不稳定运动、实验纹理

颜色提示：琥珀色控件编辑普通 BASE 值，青色控件编辑 LFO 设置。在 LFO 页面移动共用推子时，改变的是所选 LFO 字段，而非目标的基础值。

BANK · 预设与存储

共有 11 个预设。GTR–SYN 不只使用基础波形，还会载入各乐器专用的谐波结构和 ADSR；M1–M5 会连同该音色结构保存完整编辑状态。

按钮含义音色方向
GTR / PNO吉他 / 钢琴逐渐衰减的弦谐波／增强第三分音的钢琴频谱
ORG / REC风琴 / 竖笛突出 1:2:3:6 的持续音／基频主导、偶次谐波较弱
PAD / PLK / BEL铺底 / 拨弦 / 钟声柔和持续／明亮短拨弦／带稀疏高分音的敲击音
BRS / BAS / SYN铜管 / 贝司 / 合成器低次谐波厚实／基频突出的低音／带限锯齿谐波列
RND随机随机组合音色结构、数值和效果器
M1–M5存储槽先保存离开的槽，再载入目标槽

提示：载入预设后再按 SINE、SAW、SQUARE 或 TRIANGLE，会取消乐器专用音色并回到普通基础波形。

演奏 · XY 触控板与键盘

XY 触控板和两八度触摸键盘都能触发音符，并支持滑动演奏。

PERFORMANCE XY

X 轴覆盖 MIDI 48–96。SEMITONE 量化为半音；CONTINUOUS 允许连续音高。Y 轴作为演奏位置传给音频端，用于表现控制。

TOUCH KEYBOARD

直接演奏白键和黑键。滑动时释放前一个音并触发下一个音；最多 7 复音，可演奏和弦。

白键
自然音 C D E F G A B
黑键
升/降半音
范围
约从 C3 开始的两八度
