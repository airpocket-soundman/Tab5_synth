# Tab5 Synth ユーザーマニュアル

[図解 HTML 版（日本語）](https://airpocket-soundman.github.io/Tab5_synth/) · [English](manual.en.md) · [中文](manual.zh-CN.md)

Tab5 Synth は、M5Stack Tab5 上で動作する最大 8 ボイスのタッチシンセサイザです。4 種類のオシレータ、マイクサンプル、外部 I2S 入力、ADSR、4 系統の FX、パラメータ別 LFO、プリセット、XY パッド、2 オクターブ鍵盤を備えます。

## 基本操作

1. 最上段で `SINE` / `SAW` などの音源を選ぶ。
2. `AMP` または `FX` でパラメータを選ぶ。
3. エディタ下部の共通横フェーダーで値を 0–100 の範囲で変える。
4. 鍵盤または XY パッドをタッチして演奏する。

## 音源

| 音源 | 意味 | 向いている音 |
|---|---|---|
| `SINE` | 純粋なサイン波。「sing」と書かれることがありますが UI 表記は SINE です | サブベース、笛、柔らかいリード |
| `SAW` | 倍音の多いノコギリ波 | ストリングス、ブラス、太いリード |
| `SQUARE` | 中空で電子的な矩形波 | 8-bit、ベース、簧系 |
| `TRIANGLE` | 穏やかな三角波 | ベル、柔らかいベース |
| `MIC` | 押している間に録音し、離すとサンプル化 | 声、打音、身近な音 |
| `I2S` | 外部デジタル音声入力 | AtomS3 などの外部音源 |

`MIC` は 1 秒以上押し続けます。1 秒未満は破棄され、最大録音時間は 5 秒です。Web シミュレータは UI 確認用で、実際の録音と発音には Tab5 実機が必要です。

## AMP とエンベロープ

```text
音量
 ^         peak
 |        /\
 |       /  \_________ sustain
 |      /              \
 |_____/________________\____> 時間
       A   D       S     R
       押鍵              離鍵
```

| パラメータ | 意味 |
|---|---|
| `VOL` | 全体出力音量 |
| `ATK` | Attack。押鍵から最大音量までの時間 |
| `DEC` | Decay。最大音量からサステインレベルまで下がる時間 |
| `SUS` | Sustain。押している間の保持音量。時間ではなくレベル |
| `REL` | Release。離鍵から無音までの時間 |

短い音は ATK/DEC を小さく SUS を低くします。パッド音は ATK/REL を大きくすると、ゆっくり現れて余韻が残ります。

## FX

処理順は `SOURCE → DELAY → CHORUS → DRIVE → CRUSH → OUTPUT` です。エフェクト名ボタンは選択と ON/OFF を兼ね、OFF 中も値を編集できます。

| FX | パラメータ | 意味 |
|---|---|---|
| Delay | `TIME` | 反響までの間隔 |
|  | `FBK` | フィードバック量。繰り返しの長さ |
|  | `MIX` | ディレイ音の混合量 |
| Chorus | `RATE` | 揺れの速さ |
|  | `DEP` | 揺れの深さ |
|  | `MIX` | コーラス音の混合量 |
| Drive | `DRV` | 歪みの強さ |
|  | `TON` | 歪み後の明るさ |
|  | `MIX` | 歪み音の混合量 |
| Crush | `BITS` | 量子化の粗さ |
|  | `RATE` | サンプル更新の粗さ |
|  | `MIX` | クラッシュ音の混合量 |

## LFO

LFO は AMP/FX の各パラメータを自動的に揺らします。17 個の対象それぞれが `RAT`、`DEP`、波形、ON/OFF を独立して保持します。

1. AMP または FX で対象パラメータを選ぶ。
2. `LFO` タブへ移り、`TARGET` 表示を確認する。
3. `RAT`（速度）と `DEP`（深さ）を設定する。
4. `SINE` / `TRIANGLE` / `SQUARE` / `RND` を選び、`LFO ON` にする。

アンバー系は通常値、シアン系は LFO 設定です。LFO 画面で共通フェーダーを動かすと、対象の元値ではなく選択中の LFO 値が変わります。

## BANK

| ボタン | 内容 |
|---|---|
| `GTR PNO ORG REC` | Guitar / Piano / Organ / Recorder |
| `PAD PLK BEL` | Pad / Pluck / Bell |
| `BRS BAS SYN` | Brass / Bass / Synth |
| `RND` | 音源、値、FX を組み合わせたランダム音色 |
| `M1`–`M5` | 編集メモリ。移動前に現在スロットを保存してから移動先を読み込む |

## XY パッドと鍵盤

- XY の X 軸は MIDI 48–96 の音程です。
- `SEMITONE` は半音単位、`CONTINUOUS` は連続音程です。
- Y 軸は演奏位置としてオーディオ側に渡されます。
- 下部鍵盤は約 2 オクターブで、白鍵が自然音、黒鍵がシャープ/フラットです。
- スワイプ演奏と最大 8 音の和音に対応します。

画面図と操作可能なシミュレータは [HTML マニュアル](https://airpocket-soundman.github.io/Tab5_synth/#simulator) を参照してください。
