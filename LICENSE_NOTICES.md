## Web preview dependencies

The portable UI module uses the LVGL implementation supplied by Web Simulator
for LVGL. The simulator, LVGL, built-in fonts, image decoder, C/C++ runtimes,
and their complete license texts are listed in the preceding simulator notices.

M5Unified, M5GFX, Arduino-ESP32, and ESP-IDF are used only by the device
firmware build and are not included in the web preview application module.
